# Neon City

Neon-racer door een cyberpunkstad bij nacht: tien districten, skyway, metrotunnels, rivalen, power-ups, missies en een garage.

Speel en installeer: https://rensswinnen18.github.io/neon-city/

- **Android:** open de link in Chrome en tik op *Installeer als app* (of kies *App installeren* in het menu).
- **iPhone:** open de link in Safari, tik op het deel-icoon en kies *Zet op beginscherm*.

Na de eerste keer laden werkt de game ook offline.
